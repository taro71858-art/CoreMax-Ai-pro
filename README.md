# CoreMaX AI — Бизнес-аналитик 📊

Умное премиальное мобильное приложение для бизнеса с нуля. Автоматически рассчитывает прибыль, маржу, наценку, находит причины убытков, конвертирует валюты по реальным курсам, выставляет счета и даёт финансовые советы через встроенного ИИ-советника.

## 🚀 Описание проекта
Приложение разработано для платформ Android с использованием современных технологий:
- **Язык**: Kotlin
- **Интерфейс**: Jetpack Compose (Material 3)
- **ИИ-модель**: ИИ-советник на базе модели `gemini-3.5-flash`
- **Темизация**: 4 встроенных темы (Темная премиальная, Светлая, Системная и Монохромная Ч/Б)

---

## 🛠️ Структура проекта

### 📱 Android-клиент (`/app`)
- **MainActivity**: Единая точка входа, координирующая навигацию между 5 разделами нижней панели и 24 специализированными инструментами.
- **Интегрированные модули**:
  - `AnalysisScreen`: Ввод показателей, оценка здоровья бизнеса, автоматический разбор причин убытков.
  - `WhatIfScreen`: Интерактивные ползунки чувствительности для моделирования пессимистичного/оптимистичного сценариев.
  - `AdvisorScreen`: Чат-интерфейс с ИИ-советником (потоковый вывод, адаптивный контекст данных предприятия).
  - `CurrenciesScreen`: Мультивалютный конвертер (более 256 валют мира, металлы, криптовалюты).
  - `HistoryScreen`: Локальное сохранение расчетов, журнал транзакций доходов/расходов (ДДС), сравнение двух расчетов бок-о-бок.
- **Синтез аудио**: Нативный низкоуровневый генератор звуковых эффектов (`AudioTrack` PCM) без утяжеления медиафайлами.
- **Экспорт PDF**: Генерация печатных отчетов A4 со структурированными таблицами и рекомендациями.

### 🐍 Python Backend Server (`/backend`)
Вспомогательный сервер на Python для агрегации аналитических запросов и проксирования запросов к моделям ИИ.

## 💻 Настройка и запуск

### Запуск Android клиента
1. Установите **Android Studio (Ladybug или новее)**.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/taro71858-art/CoreMax-Ai-Business-analyst-.git
   ```
3. Добавьте API-ключ Gemini в файл `.env` в корневой папке проекта:
   ```env
   GEMINI_API_KEY=ваш_ключ_из_секретов
   ```
4. Откройте проект в Android Studio и запустите на эмуляторе или физическом устройстве.

### Запуск вспомогательного Python бэкапа (`/backend`)
1. Перейдите в папку бэкенда:
   ```bash
   cd backend
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите Flask-сервер:
   ```bash
   python server.py
   ```
